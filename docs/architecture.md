## 2. Component Specification

| Subsystem | Component Name | Technology | Status |
| :--- | :--- | :--- | :--- |
| **API** | `backend_api.py` | FastAPI, Uvicorn, Pydantic | **Implemented** |
| **Frontend** | `ui/` Dashboard | Next.js 14, React 18, Leaflet, TailwindCSS | **Implemented** |
| **Preprocessing** | `src/preprocessing/agri_features.py` | NumPy, Pandas | **Implemented** |
| **Geospatial** | `src/geospatial/fetch_soil.py` | ISRIC SoilGrids REST, ICAR Zonal Baselines | **Implemented** |
| **Geospatial** | `src/geospatial/fetch_weather.py`| Open-Meteo REST API, FAO-56 $ET_0$ | **Implemented** |
| **Geospatial** | `src/geospatial/fetch_terrain.py`| Open-Elevation DEM, XGBoost Erosion Context| **Implemented** |
| **Inference** | `src/models/agri_inference.py` | XGBoost 2.0+, Joblib, Scikit-Learn | **Implemented** |
| **Model Registry**| `models/crop/v1` - `v5` | Serialized XGBoost Classifiers, Regressors | **Implemented** |
| **Knowledge Base**| `crop_knowledge_base.json` | FAO EcoCrop / ICAR Canonical JSON Rules | **Implemented** |
| **Explainability**| TreeSHAP + `ai_explainer.py` | SHAP, Groq API (LLaMA-3.1), Local Fallback | **Implemented** |
| **Vision** | `src/vision/` Remote Sensing | DeepLabV3+, Sentinel Hub, UAV Pipeline | **Planned** |
| **Irrigation** | Advisory Engine | Water Balance Modeling (FAO-56 Dual $K_c$) | **Planned** |
